## 3D Mensuration

Cuboid:

```text
Volume = l*b*h
TSA = 2(lb + bh + hl)
LSA = 2h(l+b)
Diagonal = sqrt(l^2 + b^2 + h^2)
```

Cube:

```text
Volume = a^3
TSA = 6a^2
Diagonal = a*sqrt(3)
```

Cylinder:

```text
Volume = pi*r^2*h
CSA = 2*pi*r*h
TSA = 2*pi*r(h+r)
```

Cone:

```text
Volume = 1/3*pi*r^2*h
Slant height l = sqrt(r^2 + h^2)
CSA = pi*r*l
TSA = pi*r(l+r)
```

Sphere:

```text
Volume = 4/3*pi*r^3
Surface area = 4*pi*r^2
```

Hemisphere:

```text
Volume = 2/3*pi*r^3
CSA = 2*pi*r^2
TSA = 3*pi*r^2
```

Scaling:

```text
Length ratio = a:b
Area ratio = a^2:b^2
Volume ratio = a^3:b^3
```
