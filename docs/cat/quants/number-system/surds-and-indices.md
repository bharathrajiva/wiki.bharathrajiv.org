## Surds and Indices

Indices:

```text
a^m * a^n = a^(m+n)
a^m / a^n = a^(m-n)
(a^m)^n = a^(mn)
(ab)^n = a^n b^n
a^0 = 1
a^-n = 1/a^n
```

Surds:

```text
sqrt(ab) = sqrt(a)*sqrt(b)
sqrt(a/b) = sqrt(a)/sqrt(b)
```

Rationalization:

```text
1/(a + sqrt(b)) = (a - sqrt(b))/(a^2 - b)
```
